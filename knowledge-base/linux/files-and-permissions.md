# Файлы и права доступа в Linux

## Основы прав доступа

В Linux каждый файл и каталог имеет:

* владельца (**Owner**);
* группу (**Group**);
* права для остальных пользователей (**Others**).

Три основных типа прав:

| Символ | Право   | Описание   |
| ------ | ------- | ---------- |
| `r`    | Read    | Чтение     |
| `w`    | Write   | Запись     |
| `x`    | Execute | Выполнение |

---

# Просмотр прав

```bash
ls -l file.txt
```

Пример вывода:

```text id="w2axsr"
-rw-r--r-- 1 user group 1234 Apr 15 10:00 file.txt
```

Разбор:

```text id="6x7aia"
-rw-r--r--
││ │ │
││ │ └── Права остальных пользователей
││ └──── Права группы
│└────── Права владельца
└──────── Тип объекта
```

---

## Типы файлов

Первый символ показывает тип объекта:

| Символ | Тип                      |
| ------ | ------------------------ |
| `-`    | Обычный файл             |
| `d`    | Каталог                  |
| `l`    | Символическая ссылка     |
| `c`    | Символьное устройство    |
| `b`    | Блочное устройство       |
| `p`    | Именованный канал (FIFO) |
| `s`    | Сокет                    |

Примеры:

```text id="upom7j"
-rw-r--r--  файл
drwxr-xr-x  каталог
lrwxrwxrwx  ссылка
```

---

# Изменение прав — chmod

## Символьный метод

### Добавить право выполнения владельцу

```bash
chmod u+x script.sh
```

---

### Убрать право записи у группы и остальных

```bash
chmod go-w file.txt
```

---

### Добавить право чтения группе

```bash
chmod g+r file.txt
```

---

### Убрать выполнение у остальных

```bash
chmod o-x file.txt
```

---

## Обозначения

| Символ | Значение               |
| ------ | ---------------------- |
| `u`    | Владелец (user)        |
| `g`    | Группа (group)         |
| `o`    | Остальные (others)     |
| `a`    | Все пользователи (all) |
| `+`    | Добавить право         |
| `-`    | Удалить право          |
| `=`    | Задать права точно     |

Примеры:

```bash
chmod a+r file.txt
chmod u=rwx,g=rx,o=r file.txt
```

---

# Числовой метод (Octal)

Каждое право имеет числовое значение:

| Право | Значение |
| ----- | -------- |
| `r`   | 4        |
| `w`   | 2        |
| `x`   | 1        |

Сумма значений определяет итоговые права.

---

## Таблица значений

| Число | Права | Описание                   |
| ----- | ----- | -------------------------- |
| 7     | rwx   | Чтение, запись, выполнение |
| 6     | rw-   | Чтение и запись            |
| 5     | r-x   | Чтение и выполнение        |
| 4     | r--   | Только чтение              |
| 0     | ---   | Нет прав                   |

---

## Популярные комбинации

### 755

```bash
chmod 755 script.sh
```

Результат:

```text id="yl3vw8"
rwxr-xr-x
```

| Кто       | Права |
| --------- | ----- |
| Владелец  | rwx   |
| Группа    | r-x   |
| Остальные | r-x   |

Используется для:

* исполняемых файлов;
* каталогов.

---

### 644

```bash
chmod 644 file.txt
```

Результат:

```text id="x0l4fq"
rw-r--r--
```

Используется для обычных файлов.

---

### 600

```bash
chmod 600 secret.txt
```

Результат:

```text id="m0hqcp"
rw-------
```

Только владелец имеет доступ.

---

### 700

```bash
chmod 700 private.sh
```

Результат:

```text id="qgz7gt"
rwx------
```

Только владелец имеет полный доступ.

---

# Изменение владельца

## Сменить владельца и группу

```bash
sudo chown user:group file.txt
```

---

## Рекурсивно для каталога

```bash
sudo chown -R user:group dir/
```

---

## Изменить только владельца

```bash
sudo chown user file.txt
```

---

## Изменить только группу

```bash
sudo chown :developers file.txt
```

или

```bash
sudo chgrp developers file.txt
```

---

# Права по умолчанию — umask

Параметр `umask` определяет, какие права будут убраны у новых файлов и каталогов.

Посмотреть текущее значение:

```bash
umask
```

---

## Пример

```bash
umask 022
```

Новые объекты будут создаваться с правами:

| Тип     | Итоговые права |
| ------- | -------------- |
| Файл    | 644            |
| Каталог | 755            |

---

### Расчёт

Файлы создаются из базового шаблона:

```text id="j3v05y"
666 - umask
```

Каталоги:

```text id="4i7n0g"
777 - umask
```

Пример:

```text id="r6f9wy"
666 - 022 = 644
777 - 022 = 755
```

# Специальные биты

## Sticky Bit

Используется для общих каталогов.

```bash
chmod +t dir/
```

Пример:

```text id="j7gtns"
drwxrwxrwt
```

Последняя буква:

```text id="s1c6ij"
t
```

означает Sticky Bit.

---

### Назначение

Пользователь может удалять:

* только свои файлы;
* либо файлы, владельцем которых является root.

---

### Пример

Каталог:

```text id="c2r3kt"
/tmp
```

Обычно имеет права:

```text id="r2jlwm"
drwxrwxrwt
```

---

## SetGID

Новые файлы наследуют группу каталога.

```bash
chmod g+s dir/
```

Пример:

```text id="7gqvyr"
drwxrwsr-x
```

Полезно для:

* общих рабочих каталогов;
* командной разработки.

---

## SetUID

Программа запускается с правами владельца файла.

```bash
chmod u+s file
```

Пример:

```text id="k3d7ta"
-rwsr-xr-x
```

---

### Классический пример

```bash
ls -l /usr/bin/passwd
```

Можно увидеть:

```text id="k3l3pi"
-rwsr-xr-x
```

Благодаря SetUID обычный пользователь может изменить свой пароль через программу `passwd`.

---

# Проверка специальных битов

```bash
ls -l
```

Примеры:

```text id="9o2nyh"
-rwsr-xr-x  SetUID
drwxrwsr-x  SetGID
drwxrwxrwt  Sticky Bit
```

---

# Поиск файлов по правам

## Найти все файлы с правами 777

```bash
find / -type f -perm 777 2>/dev/null
```

---

## Найти файлы с SetUID

```bash
find / -perm -4000 2>/dev/null
```

---

## Найти файлы с SetGID

```bash
find / -perm -2000 2>/dev/null
```

---

# ACL (расширенные права)

Стандартных прав иногда недостаточно.

Посмотреть ACL:

```bash
getfacl file.txt
```

---

Выдать право пользователю:

```bash
setfacl -m u:user:rwx file.txt
```

---

Удалить ACL:

```bash
setfacl -b file.txt
```

---

# Полезная шпаргалка

| Команда                 | Назначение          |
| ----------------------- | ------------------- |
| `ls -l`                 | Показать права      |
| `chmod 755 file`        | Изменить права      |
| `chown user:group file` | Изменить владельца  |
| `chgrp group file`      | Изменить группу     |
| `umask`                 | Показать маску прав |
| `chmod +t dir`          | Sticky Bit          |
| `chmod g+s dir`         | SetGID              |
| `chmod u+s file`        | SetUID              |
| `getfacl file`          | Посмотреть ACL      |
| `setfacl`               | Настроить ACL       |

---

# Самые популярные права

| Права | Значение  | Где используются   |
| ----- | --------- | ------------------ |
| `644` | rw-r--r-- | Обычные файлы      |
| `600` | rw------- | Конфиги, ключи     |
| `755` | rwxr-xr-x | Каталоги, скрипты  |
| `700` | rwx------ | Приватные каталоги |
| `777` | rwxrwxrwx | Не рекомендуется   |
