# Управление процессами в Linux

## Что такое процесс

**Процесс** — это выполняемая программа, которой операционная система выделяет:

* память;
* процессорное время;
* файловые дескрипторы;
* сетевые соединения;
* другие ресурсы.

Каждый процесс имеет уникальный идентификатор — **PID (Process ID)**.

---

# Просмотр процессов

## Процессы текущего терминала

```bash
ps
```

---

## Все процессы (BSD-формат)

```bash
ps aux
```

Пояснение колонок:

| Поле    | Значение               |
| ------- | ---------------------- |
| USER    | Владелец процесса      |
| PID     | Идентификатор процесса |
| %CPU    | Использование CPU      |
| %MEM    | Использование памяти   |
| VSZ     | Виртуальная память     |
| RSS     | Физическая память      |
| TTY     | Терминал               |
| STAT    | Состояние              |
| COMMAND | Команда запуска        |

---

## Все процессы (System V)

```bash
ps -ef
```

---

## Сортировка по загрузке CPU

```bash
ps aux --sort=-%cpu
```

Самые активные процессы будут сверху.

---

## Сортировка по памяти

```bash
ps aux --sort=-%mem
```

---

## Процессы конкретного пользователя

```bash
ps -u user
```

---

# Динамический просмотр процессов

## top

```bash
top
```

Полезные клавиши:

| Клавиша | Действие                   |
| ------- | -------------------------- |
| `q`     | Выход                      |
| `k`     | Завершить процесс          |
| `M`     | Сортировка по памяти       |
| `P`     | Сортировка по CPU          |
| `1`     | Показать загрузку по ядрам |

---

## htop

Установка:

```bash
sudo apt install htop
```

Запуск:

```bash
htop
```

Полезные клавиши:

| Клавиша | Действие          |
| ------- | ----------------- |
| `F3`    | Поиск             |
| `F4`    | Фильтр            |
| `F5`    | Дерево процессов  |
| `F6`    | Сортировка        |
| `F9`    | Завершить процесс |
| `F10`   | Выход             |

# Запуск процессов

## Foreground (передний план)

```bash
./script.sh
```

Терминал будет занят до завершения процесса.

---

## Background (фоновый режим)

```bash
./script.sh &
```

Терминал сразу вернётся к приглашению командной строки.

---

## Независимый запуск (nohup)

```bash
nohup ./script.sh &
```

Вывод по умолчанию:

```text
nohup.out
```

Процесс продолжит работать даже после закрытия терминала.

---

# Управление заданиями (Jobs)

Работает только в текущей оболочке Bash.

---

## Список фоновых задач

```bash
jobs
```

Пример:

```text
[1]+ Running ./backup.sh &
```

---

## Вернуть задачу на передний план

```bash
fg %1
```

---

## Перевести остановленную задачу в фон

```bash
bg %1
```

---

## Приостановить текущий процесс

Нажать:

```text
Ctrl + Z
```

Процесс получит сигнал:

```text
SIGSTOP
```

# Завершение процессов

## Корректное завершение

```bash
kill PID
```

или

```bash
kill -15 PID
```

Отправляется сигнал:

```text
SIGTERM
```

---

## Принудительное завершение

```bash
kill -9 PID
```

Отправляется:

```text
SIGKILL
```

Процесс завершается немедленно.

---

## Аналог Ctrl+C

```bash
kill -2 PID
```

Сигнал:

```text
SIGINT
```

---

## Перечитать конфигурацию

```bash
kill -1 PID
```

Сигнал:

```text
SIGHUP
```

Часто используется для:

* nginx;
* apache;
* sshd;
* других демонов.

---

# Отправка сигналов по имени

```bash
kill -TERM PID
kill -KILL PID
kill -INT PID
kill -HUP PID
```

```bash

```

---

## Поиск по полной командной строке

```bash
pkill -f script.py
```

---

## killall

```bash
killall nginx
```

Убивает процессы с точным именем.

# Приоритеты процессов

В Linux планировщик использует значение **nice**.

Диапазон:

```text
-20  ...  19
```

| Значение | Приоритет    |
| -------- | ------------ |
| -20      | Максимальный |
| 0        | Обычный      |
| 19       | Минимальный  |

---

## Запуск с низким приоритетом

```bash
nice -n 10 ./script.sh
```

---

## Запуск с высоким приоритетом

```bash
sudo nice -n -5 ./script.sh
```

---

## Изменение приоритета работающего процесса

```bash
renice -n 5 -p PID
```

---

## Для всех процессов пользователя

```bash
sudo renice -n -10 -u user
```

# Каталог /proc

Каждый процесс имеет каталог:

```text
/proc/PID/
```

Примеры:

```bash
ls /proc/1234
```

Полезные файлы:

| Файл    | Назначение            |
| ------- | --------------------- |
| status  | Информация о процессе |
| cmdline | Команда запуска       |
| environ | Переменные окружения  |
| fd/     | Открытые файлы        |
| maps    | Карта памяти          |
| stat    | Статистика процесса   |

---

# Основные сигналы Linux

| Сигнал  | Номер | Назначение             |
| ------- | ----- | ---------------------- |
| SIGHUP  | 1     | Перечитать конфиг      |
| SIGINT  | 2     | Ctrl+C                 |
| SIGQUIT | 3     | Выход с дампом памяти  |
| SIGKILL | 9     | Немедленное завершение |
| SIGTERM | 15    | Корректное завершение  |
| SIGSTOP | 19    | Остановить процесс     |
| SIGCONT | 18    | Продолжить выполнение  |

---

# Просмотр всех сигналов

```bash
kill -l
```

---

# Состояния процессов

Выводятся в колонке `STAT` команды `ps`.

| Состояние | Значение               |
| --------- | ---------------------- |
| R         | Выполняется            |
| S         | Ожидание               |
| D         | Непрерываемое ожидание |
| T         | Остановлен             |
| Z         | Zombie                 |
| I         | Idle (ядро)            |

---

## Поиск zombie-процессов

```bash
ps aux | grep Z
```

или

```bash
ps -el | grep Z
```

# Полезные алиасы

Добавить в файл:

```bash
~/.bashrc
```

---

## Топ процессов по CPU

```bash
alias pscpu='ps aux --sort=-%cpu | head -20'
```

---

## Топ процессов по памяти

```bash
alias psmem='ps aux --sort=-%mem | head -20'
```

---

## Процессы текущего пользователя

```bash
alias myps='ps -u $USER'
```

Применить изменения:

```bash
source ~/.bashrc
```
